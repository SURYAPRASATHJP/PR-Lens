# PR-Lens

An opt-in GitHub App that leaves line-level review comments on pull requests.

It is aimed at people who have no reviewer: solo projects, students, two-person
teams. It reads the repository's own history for context, runs the project's tests
in a network-isolated sandbox, and drafts a comment only when it has something
specific to say.

**Status: Phase 0.** The webhook spine is built and tested. There is no review
intelligence yet. Do not install this on anything you care about.

## What it will not do

- It never opens pull requests, never pushes, never applies suggestions, and never
  approves. The App requests `contents: read`, so this holds at the token level and
  not only in the code.
- Every comment carries a line saying it was generated by an AI.
- Saying nothing is a valid outcome, and one that gets measured. A reviewer that
  comments on everything is worse than no reviewer.

## Measured quality

Acceptance rate and noise rate go here as numbers, alongside hit rate, substance
match, silence accuracy, cost per pull request and p95 latency. They are absent
because they have not been measured yet, not because they are flattering.

## How it is put together

```
pull request event
  -> Hugging Face Space (FastAPI in Docker)
       verify HMAC SHA-256, else 401
       record the delivery in Postgres, unique on GitHub's delivery id
       fire repository_dispatch
       return 202
  -> GitHub Actions
       retrieval, sandboxed test run, drafting, posting
```

The Space does no thinking. It verifies, records, dispatches and returns, well
inside GitHub's ten second webhook timeout. Everything expensive runs as an Actions
job on this public repo, where standard runners are free and unlimited.

## Running it locally

```
uv sync
uv run ruff check . && uv run ruff format --check .
uv run mypy .
uv run pytest
uv run uvicorn pr_lens.api.main:app --reload
```

Database tests need a Postgres to talk to and skip without one:

```
docker run -d --name pr-lens-pg -e POSTGRES_PASSWORD=postgres -p 55432:5432 postgres:16
DATABASE_URL=postgresql://postgres:postgres@localhost:55432/postgres uv run pytest
```

Apply migrations with `uv run python -m pr_lens.db.migrate`.

## Configuration

Every value comes from the environment. See `.env.example` for the full list and
